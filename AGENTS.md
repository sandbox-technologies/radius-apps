# Radius Apps contributor instructions

This is a standalone app/catalog repository, not the Radius browser source.
Apps may use only the documented `radius.apps/1` contract. Never import Radius
internals, add privileged preload/IPC access, or assume current browser focus.

- Use `pnpm install --ignore-scripts --frozen-lockfile`, then `pnpm check`.
- App bundles live in `apps/<slug>/bundle`; contributor metadata and tests stay outside the installed bundle.
- Keep all runtime assets local. No install hooks or remote executable code.
- Treat unit-test host doubles as developer aids, not security sandboxes.
- Installation must not enable schedules, start agents, or approve permissions.
- Agent generation and the Focus Layout draft action remain unavailable on the current experimental host.
- PR validation has no signing secrets. Signing is a separate maintainer-approved workflow.
- Do not publish, grant a license, add trust keys, enable schedules, or invoke models as an incidental test.
- Preserve immutable version/digest mappings and security revocations when updating a catalog.
- Use the shared 80 ms interaction duration for new UI motion, respecting Reduced Motion. Never use it as an input delay.

The vendored SDK is generated by Radius. Do not hand-edit it: use its SOURCE.json
to identify the upstream exporter and version, then update it as one reviewed change.
