# Changelog

## 0.1.0 — synthetic report fixture

- Added a deterministic worker that publishes escaped, script-free and
  network-free HTML from controlled synthetic input and host logical time.
- Declared owned artifact publication and a separate optional open requirement;
  the daily trigger is a suggestion, never enabled by installation.
- Added explicit disposable-profile usage instructions and public-SDK/unit
  tests. Experimental; native scheduler, delivery and presentation are not
  verified by these tests. No AI generation or Morning Brief substitution.
- Included the repository's approved MIT license unchanged in the bundle.
